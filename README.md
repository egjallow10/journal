# Journal

An AI-powered personal journal application that analyzes your thoughts and identifies your emotional state in real-time.

## Overview

This innovative journal uses artificial intelligence to understand and reflect back your emotional mood based on the thoughts and experiences you record. As you write your daily entries, the AI analyzes your text and provides insights into your current emotional state, helping you gain deeper self-awareness and track your emotional patterns over time.

## Features

- ✍️ **AI Mood Detection** - Write your thoughts and get instant AI analysis of your emotional state
- 🎯 **Emotional Insights** - Discover patterns in your mood and emotions
- 📅 **Chronological Organization** - Entries are automatically organized by date with mood tracking
- 🔍 **Search Functionality** - Find past entries by keywords, dates, or emotional mood
- 💾 **Persistent Storage** - All entries and mood analyses are securely saved
- 📊 **Mood History** - Visual tracking of your emotional journey over time
- 🤖 **AI Analysis** - Real-time natural language processing to understand your feelings

## Tech Stack

- **Frontend**: Next.js with React
- **AI/ML**: Natural Language Processing for mood detection
- **Styling**: CSS/Tailwind CSS
- **Runtime**: Node.js

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm, yarn, pnpm, or bun package manager

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/egjallow10/journal.git
   cd journal
   ```

2. Install dependencies:
   ```bash
   npm install
   # or
   yarn install
   # or
   pnpm install
   # or
   bun install
   ```

3. Start the development server:
   ```bash
   npm run dev
   # or
   yarn dev
   # or
   pnpm dev
   # or
   bun dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to access your AI journal.

## How It Works

1. **Write Your Thoughts** - Open the journal and type your daily thoughts, feelings, or experiences
2. **AI Analysis** - The application analyzes your text in real-time
3. **Mood Detection** - Your emotional state is identified and displayed (e.g., Happy, Anxious, Calm, Excited, Reflective, etc.)
4. **Track Patterns** - Review your mood history to understand your emotional patterns
5. **Reflect** - Use these insights for personal growth and self-reflection
